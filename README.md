# Visagem

Jogo de navegador no estilo *survivors*: um vaqueiro perdido no sertão precisa sobreviver 30 minutos às assombrações do folclore até o sol nascer.

**Jogar:** https://dmwnezes.com/survival

## Como jogar
- **PC:** WASD ou setas para andar, `P` ou `Esc` para pausar, teclas `1` a `4` para escolher cartas.
- **Celular:** toque e arraste em qualquer lugar da tela (o joystick aparece onde o dedo encosta, ou fica fixo no canto se você escolher no menu). Jogue deitado.
- As armas atacam sozinhas. Pegue os cajus para subir de nível e escolher melhorias.
- Arma no nível 8 + o item certo = evolução.

## Publicar
O jogo está em `index.html` e na pasta `js/` (scripts carregados em ordem: base, dados, conteudo, mundo, armas, jogo, desenho, telas, extra), sem dependências; `manifest.webmanifest`, `sw.js` e os ícones cuidam da instalação e do modo offline. No GitHub: **Settings → Pages → Branch `main` / root**. Como o domínio `dmwnezes.com` já aponta para o site principal, o jogo aparece em `dmwnezes.com/survival`.

## Testes
Adicione `?speed=4` ao endereço para acelerar o tempo (até 10x) e chegar mais rápido aos chefões.
